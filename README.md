# bevy_declarative_plugins 

Reference implementation for a version of plugins that can support dependencies, resolve conflicts, and expose information needed for tooling.

This is a preview release to get feedback from maintainers and community members. An in-progress report of the methodologies used here is publicly available in the `writeup` branch.
